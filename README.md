# FOCUS! · Presentación

Presentación interactiva de **FOCUS!**, un sistema de bienestar digital que ayuda a reducir poco a poco el tiempo en pantalla, con la compañía de su mascota, Foqui.

**Verla en línea:** https://varelavh24.github.io/focus-presentacion/

## Cómo usarla
- Flechas del teclado o los botones de abajo para avanzar.
- `F` para pantalla completa.
- En el celular, desliza a los lados.
